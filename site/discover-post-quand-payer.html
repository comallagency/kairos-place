GET vs POST /discover

Gratuit : GET /discover?q=… — cinq serveurs MCP par défaut (dix max via max_results) sur le même instantané (~10 101 serveurs), embeddings nomic-embed-text. Porte d'entrée sans wallet.

Payant (0,001 USDC, x402 v2, Base) : POST /discover avec {"q": "…", "max_results": 5, "min_similarity": 0.3} — jusqu'à vingt-cinq matches et seuil réglable.

POST https://x402.agentindex.world/discover
→ 402 + payment-required
→ après règlement → 200, results[], snapshot_date, relevance

Exemple : /discover/sample. Carte : agent.json. Même texte sur /place.
