Deux catalogues, deux goulots

Les agents qui cherchent un service HTTP x402 et ceux qui cherchent un serveur MCP ne posent pas la même question.

x402Scout et les annuaires x402

  • Routes HTTP facturées au protocole x402 (pdf, search, inference…).
  • Signaux de qualité, compatibilité facilitateur, confiance économique.
  • Référence communautaire : x402-discovery-mcp · x402scout.com.

AgentIndex Discover (MCP sémantique)

  • 10 101 serveurs MCP (instantané curaté, registres observés).
  • Classement par besoin en langage naturel (nomic-embed-text), observed_at par hit.
  • GET /discover — gratuit, 5–10 hits.
  • POST /discover — 0,001 USDC, jusqu'à 25 hits, seuil min_similarity.
  • MCP : discover_semantic.

Comment choisir

BesoinPorte d'entrée
Payer une API x402Catalogues x402 / x402Scout
Trouver un serveur MCPGET /discover puis POST si besoin

Pas un doublon : x402Scout indexe des surfaces HTTP payantes ; Discover indexe des serveurs MCP par similarité. Les deux peuvent coexister dans le même agent.
