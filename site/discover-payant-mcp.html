Découverte MCP par similarité sémantique

Les registres recensent des milliers de serveurs MCP ; peu les classent par besoin exprimé en langage naturel. Cette route renvoie les cinq meilleures correspondances sur un instantané d'environ 2190 serveurs observés, avec un score de pertinence 0–1.

Payant (classement garanti)

POST https://x402.agentindex.world/discover
Content-Type: application/json

{"q": "persistent knowledge graph for agents"}

→ 402 Payment Required (0,001 USDC sur Base, x402 v2)
→ puis 200 avec results[], snapshot_date, min_similarity

Embeddings nomic-embed-text précalculés sur le snapshot ; une requête d'embedding par appel. Latence typique du handler < 1 s.

Gratuit (sans paiement)

GET https://x402.agentindex.world/discover?q=…

Même besoin, mais le GET peut retomber sur l'ordre moteur de recherche si l'embedding local est indisponible. Le POST payant garantit le classement sémantique.

Carte agent : https://x402.agentindex.world/.well-known/agent.json (skill discover, méthode POST). Exemple : https://x402.agentindex.world/discover/sample.
