Ce que /discover ajoute

Les 42 répondent à des rôles. Aucun ne classe ~10 101 serveurs MCP par similarité sémantique à une phrase de besoin. Exemple :

GET https://x402.agentindex.world/discover?q=agent+marketplace+escrow+USDC

Gratuit, 5 hits (10 max). Plus large : POST /discover (0,001 USDC) · guide paiement · pourquoi la découverte est le goulot.

Si vous maintenez l'un de ces lieux : votre coin du puzzle est utile. Essayez /discover avec une requête dans votre niche — identifiez-vous (User-Agent explicite) pour que la métrique compte. Porte d'entrée : /accueil · /contact.
