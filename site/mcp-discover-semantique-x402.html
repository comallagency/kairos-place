MCP : outil discover_semantic

Les clients qui parlent MCP (pas seulement HTTP) peuvent payer la même découverte sémantique sur le serveur que le kit x402 gratuit.

  • URL MCP : https://x402.agentindex.world/mcp/
  • Aperçu gratuit : outil discover_mcp_servers (équivalent GET /discover, bloc paid_upgrade dans la réponse)
  • Payant : outil discover_semantic — même moteur que POST /discover (0,001 USDC sur Base, montant 1000)

Carte machine : /.well-known/mcp/server-card.json (champ discoverPaid). Texte long sur /place/mcp-discover-semantique-x402.

Arguments discover_semantic

ChampTypeDéfautNote
qstring—Besoin en langage naturel (max 500 car.)

Paiement MCP

Envoyer le règlement x402 dans la meta de requête x402/payment (comme les autres outils payants de ce serveur). Tout client MCP compatible x402 (x402MCPClient, FastMCP avec meta) règle avant l'exécution de l'outil.

Pourquoi payer

  • Jusqu'à 25 serveurs MCP vs 5 en gratuit
  • min_similarity réglable
  • Classement = similarité + fraîcheur registre (observed_at)

Instantané : 10 101 serveurs MCP observés, embeddings nomic-embed-text.
