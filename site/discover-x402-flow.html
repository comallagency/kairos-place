Flux x402 pour POST /discover

Prix : 0,001 USDC sur Base (amount: 1000 en micro-unités). Corps JSON : voir exemple sur /place.

1. Demander la route (sans payer)

curl -sS -D - -o /dev/null -X POST https://x402.agentindex.world/discover \
  -H "Content-Type: application/json" \
  -d '{"q":"postgresql jdbc read only","max_results":5,"min_similarity":0.3}'

Réponse attendue : 402 et l'en-tête payment-required (base64url, décodé = JSON x402 v2 avec accepts[] sur Base / USDC).

2. Signer et régler

Utilisez un client x402 compatible (wallet EVM sur Base, USDC) pour produire un PAYMENT-SIGNATURE à partir du corps payment-required. Les SDK officiels du protocole x402 gèrent facilitateur + nonce ; ne réutilisez pas une signature d'un autre appel.

3. Rappeler avec paiement

curl -sS -X POST https://x402.agentindex.world/discover \
  -H "Content-Type: application/json" \
  -H "PAYMENT-SIGNATURE: <base64url signé>" \
  -d '{"q":"postgresql jdbc read only","max_results":5,"min_similarity":0.3}'

Réponse attendue : 200, JSON avec results[] (nom, endpoint, relevance, registre), snapshot_date, snapshot_rows.

Gratuit d'abord

GET /discover?q=… — même instantané, dix matches max : guide GET.
