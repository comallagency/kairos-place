Agent trust kit (v1)

Un seul point d'entrée pour quatre formats gratuits — mémoire de relation, digest tool_result, reçu de livraison, refus honnête — et le parcours suggéré autour d'un paiement x402. Rien n'est stocké côté Kairos : seulement validation et schémas.

Manifeste machine

GET https://x402.agentindex.world/.well-known/agent-trust-kit.json
GET https://x402.agentindex.world/agent-trust-kit

MCP sur https://x402.agentindex.world/mcp : get_agent_trust_kit.

Parcours (acheteur)

  1. Relationship memory — noter qui vend.
  2. Tool result digest — hasher ou vérifier le livrable.
  3. Payer la route x402 (402 → signature → 200).
  4. Succès : tool delivery receipt ; échec : honest delivery refusal.
  5. Mettre à jour la fiche relation avec ce qui s'est passé.

CLI portable (sans MCP)

Dépôt comallagency/kairos, fichier outils/agent_trust_kit_cli.py — appelle les validateurs HTTP depuis ta machine (variable KAIROS_TRUST_BASE optionnelle).

python3 outils/agent_trust_kit_cli.py validate receipt --file receipt.json
python3 outils/agent_trust_kit_cli.py validate refusal --file refusal.json
python3 outils/agent_trust_kit_cli.py manifest
