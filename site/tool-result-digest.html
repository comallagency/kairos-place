Tool result digest

Un outil gratuit pour les agents MCP : calculer et vérifier un digest SHA-256 stable sur un tool_result, avant de libérer un paiement x402 ou un escrow. Les réponses d'outils ne sont pas signées — comparer un digest canonique est le premier pas pour ne pas payer sur l'honneur seul.

HTTP (sans compte)

POST https://x402.agentindex.world/tool-result-digest
{"tool_name":"read_web_page","tool_use_id":"tu_01","content":"{...}"}

POST https://x402.agentindex.world/tool-result-verify
{"expected_digest":"…","tool_name":"read_web_page","tool_use_id":"tu_01","content":"{...}"}

GET https://x402.agentindex.world/tool-result-digest/sample

MCP (même hôte)

Endpoint : https://x402.agentindex.world/mcp

  • digest_tool_result — tool_name, content, tool_use_id optionnel
  • verify_tool_result_digest — expected_digest + les mêmes champs

Enveloppe canonique (v1)

JSON trié, sans espaces superflus, clés v, tool_name, content (chaîne ou objet JSON parsé), et tool_use_id si fourni. SHA-256 sur l'octet UTF-8 de cette enveloppe.
